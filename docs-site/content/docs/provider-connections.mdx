title: Provider connections
description: Connect generation and research services explicitly.
---

ReelBinder separates the editor from generation services. You can work with existing scripts, Projects and media without starting a model request. New generation and research need the relevant connection and configured capability.

## Connect your own services

Open ReelBinder's provider connection controls and use the supported connection flow for your deployment. Google Cloud connections use the selected project's Vertex AI access. If your deployment offers **Gemini API Key**, that route uses a Gemini key instead of a Google Cloud project connection. Each visitor supplies their own connection; access to the app is not permission to use another person's provider credentials.

Connection availability depends on your provider account, enabled APIs, permissions and model access. A connected account does not make every tool available.

Google Cloud connections require the Vertex AI API on the selected project. Connect Parallel separately so research results can include citations.

## Check access before generating

After saving a Google connection, choose **Test**. ReelBinder runs authorization and access probes and shows results for each supported tool. The test does not create content or submit a paid generation job.

A verified result confirms that the checked request path accepted the connection. It does not guarantee a later generation will succeed, create a take, or approve a creative decision.

## Review before running

Before a request, confirm the selected Project context, reference media, prompt and output type. Image, composition, video and audio are separate capabilities and may have different connection requirements.

ReelBinder uses Google ADK for assistant workflows, Google model adapters for supported generation, and Parallel Search for research. Research citations should point to sources returned by the research service; an AI observation still needs your review.

## If a request fails

Read the reported availability or job status before submitting another request. If a job remains queued past the client timeout, keep its job ID and reconnect to check it. ReelBinder preserves stalled jobs and does not automatically submit a replacement.

Disconnect services when you no longer need them. See [Architecture](/architecture) for the session and media-service boundary.
