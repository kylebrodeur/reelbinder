| File | Use it for |
|---|---|
| Rendered movie | Watching and sharing the assembled picture and sound |
| Project data JSON | Saving the editable Project structure; media references alone are not portable bytes |
| ReelBinder Project (`.reelbinder.zip`) | Moving the Project together with its supported embedded media |
| Legacy `.slate.zip` pack | Importing an older archive; still fully supported |
| Markdown and JSONL interchange | Text-based screenplay, coverage and structured production records |

## Export a portable pack

Use the Project export controls to download a ReelBinder Project. Export collects and verifies media, so a Project with several takes can take longer to prepare than a text-only file.

Wait for preparation and download completion. Check that the file has reached your downloads folder before leaving the session or removing the source media.

## Import and verify

Import the pack through ReelBinder's Project controls. Embedded media is verified and restored into the receiving session. Current asset references may change during that process; historical generation provenance stays attached to the original work.

After import, check your screenplay, setups, catalog notes, selected takes, clip trims and audio cues. Reload and play the result before treating a transfer as complete.

## Preserve the editable original

A movie is a viewing deliverable. Keep the working Project as well if you want to change timing, sound or takes later.

Treat an imported Project as creative material: code licensing does not grant rights to included screenplays, reference images or footage. Provider credentials and private runtime state do not belong in the pack.
