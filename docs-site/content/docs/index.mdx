ReelBinder brings screenplay, production notes, staging, generated media and editing into one Project. Start with the story, work out the coverage, then assemble the takes you want to keep.

## One Project, connected work

- **Script** holds the screenplay, coverage marks, production catalog and discussions.
- **Stage and Frame** connect blocking, shot settings and composition.
- **Play and Edit** let you review takes and assemble picture and sound.
- **Assistant** uses the selected context to help with production questions and proposals.

You control which proposals become edits and when a generation request runs. Editing existing material does not require a model connection; new generation uses an explicit provider connection.
